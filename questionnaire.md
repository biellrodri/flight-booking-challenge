## 🧠 How would you explain a database to a non-technical person?

I would explain it as an organized house.

The database is the house, and each room stores a specific type of item. For example, the refrigerator stores perishable food, the pantry stores dry food, and the laundry room stores cleaning products.

When preparing a meal, you collect items from different places — this represents relationships between data.

Similarly, in a database, information is stored in an organized way and connected so it can be accessed efficiently.

## 🧠 What is a variable in programming?

A variable is a space in memory used to store data that can be used and modified during program execution, such as numbers, text, or boolean values.
